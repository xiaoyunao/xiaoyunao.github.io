# Homepage tidal-stream model

The homepage uses physical Galactocentric particle snapshots generated by `scripts/generate_stream.py`, not a hand-drawn curve, rotating flat image or simulation running in the visitor's browser. The JavaScript renderer projects the same three-dimensional coordinates under different viewing angles and interpolates neighboring snapshots in physical time.

## Reproduce

```sh
cd /Users/island/Desktop/personal_page
python3 -m venv .local/stream-venv
.local/stream-venv/bin/python -m pip install -r scripts/requirements-stream.txt
.local/stream-venv/bin/python -m py_compile scripts/generate_stream.py
.local/stream-venv/bin/python scripts/generate_stream.py
```

On this Mac the existing environment was created with the bundled Python 3.12, with system site packages to reuse NumPy. The generator is optional. GitHub Pages serves only the precomputed data and ordinary JavaScript; no Python, scientific libraries, Node package installation or server backend is needed for deployment.

## Physical assumptions

- Static Hernquist bulge (3.4e10 solar masses, 0.7 kpc), Miyamoto–Nagai disk (1e11 solar masses, a=6.5 kpc, b=0.26 kpc) and spherical NFW halo (scale radius 20 kpc). The halo mass is solved for a total circular speed of 232 km/s at 8.2 kpc.
- Palomar 5-like present-day phase space: RA 229.018 deg, Dec -0.124 deg, distance 20.6 kpc, proper motions (-2.754, -2.643) mas/yr and radial velocity -58.61 km/s. Astropy v4.0 Galactocentric frame defaults are explicit.
- Gala's modified Fardal particle-release distribution (`gala_modified=True`, seed 20261027); progenitor Plummer potential with mass 20,000 solar masses and scale 15 pc. Both tails are generated. Stream tracers feel the Milky Way and progenitor potentials; tracer self-gravity and progenitor mass evolution are omitted.
- First integrate the core backward 3 Gyr, then generate the stream forward. Integration step 1 Myr, snapshots 5 Myr apart, two particles per tail released every 8 Myr. The opening starts at age 0 Gyr and plays at 48 Myr per wall-clock second; the full 3 Gyr interval takes 62.5 seconds, then automatically restarts at 0 Gyr.
- The luminous disk uses the generated transparent texture `images/milky-way-disk.png`, projected into the galactic plane with a soft radial edge. Rotation and viewing-angle controls use the same 3D projection as the particle coordinates. Asset prompt and workflow are in docs/GALAXY_ASSET.md.
- The core and stream retain the exported coordinate scale; a small glow and Star cluster label identify the progenitor on screen.

## Export and numerical checks

- `assets/data/tidal-stream.json`: shape, physical scale, time step, release times, tail membership, seed, library version, parameters and validation results.
- `assets/data/tidal-stream.bin.gz`: gzip-compressed little-endian int16 array, ordered frame/particle/xyz. Particle zero is the core; -32768 marks unreleased particles. Quantization unit is 0.002 kpc, so each component has at most 1 pc rounding error.
- 601 frames, 1,504 tail tracers plus the core; 752 tracers per tail. Current binary transfer is approximately 2.37 MB.
- Generation asserts finite active coordinates, monotonic release counts, no quantization overflow, maximum quantization error <=1 pc, and core relative energy drift <1e-6. Actual drift for this export is 1.12e-9.
- `.local/stream-model/snapshots.h5`, `diagnostics.npz` and `stream-diagnostic.png` are local-only scientific checks. The diagnostic uses physical coordinates and equal spatial scale.
- `images/stream-poster.jpg` is a capture of the same browser canvas at 0 Gyr, with interface overlays hidden on a local-only capture page. It supplies the static fallback.

The renderer pauses off screen or in a hidden tab, respects reduced-motion settings, has keyboard-operable time/view controls and supports pointer rotation. If loading or decompression is unavailable, the static poster remains visible.
