# Search visibility and Google Search Console

Canonical site: https://xiaoyunao.github.io/ (GitHub Pages; no paid domain or separate server required).

## Site configuration

- `_pages/about.md`: custom search title and concise research/person description.
- `_includes/seo.html`: standard description, canonical URL, social metadata, Person identity/alternate names and profile links. `noindex: true` is available for utility pages.
- `_config.yml`: verified public profile URLs, optional Google verification token, and explicit publication exclusions for unused template examples. Sources remain available in Git.
- `/sitemap.xml` and `/robots.txt`: generated by `jekyll-sitemap`; do not edit generated `_site` files.
- `/sitemap/`: readable links to actual content; excluded from the XML sitemap and marked noindex, as is the 404 page.

## Account setup

Status (2026-10-05): ownership verified by HTML tag; token deployed in commit `5a2369f`. Homepage was unknown to Google; indexing request accepted into the priority crawl queue. Sitemap submitted and resubmitted once after a successful Google live URL test (Crawl allowed: Yes; Page fetch: Successful). The Sitemaps report still shows Couldn't fetch / zero discovered pages. Actual processing/indexing is not confirmed; recheck later. No site-side fetch defect was reproduced.

1. Sign in at https://search.google.com/search-console/ using the user's own Google account.
2. Add a **URL-prefix** property: `https://xiaoyunao.github.io/`.
3. Select **HTML tag** verification. Copy its `content` value into `google_site_verification` in `_config.yml`. The full tag may also be supplied to the maintainer, who extracts that value. Never use a made-up token or another account's token.
4. Build, commit, push, and wait for GitHub Pages deployment. Confirm the exact tag is present in the live homepage head, then click **Verify** in Search Console. Keep the token in the site after verification.
5. Submit `sitemap.xml` under **Sitemaps**.
6. Use **URL inspection** for the homepage, review its indexing status / live test, and select **Request indexing** if appropriate. Check the Publications and Education URLs as needed.
7. Record the actual verification/submission status in WORKLOG.md. Do not describe a local build or an accessible sitemap as a successful Search Console submission.

Indexing is Google's decision; submission is not a ranking or indexing guarantee. No recurring monitoring has been scheduled.
